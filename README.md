### 👋 About Me

I build perception software for autonomous vehicles — turning raw sensor data into decisions a vehicle can act on.
As a software member of **BEUN OVAT**, I'm developing the **ROS 2 autonomy stack** for our **Teknofest Robotaksi** vehicle:
real-time obstacle and moving-object detection with a **RoboSense Helios 32 LiDAR**, LiDAR odometry and an operator control center.

I care about understanding *why* a system works, not just making it run — clean architecture, readable C++ and real-world testing.

#### [Robotaksi Autonomy](https://github.com/ayberkdoruk/robotaksi-autonomy)

ROS 2 Jazzy autonomy stack for a robotaxi competition vehicle.

- 🛑 **Real-time obstacle decision** — STOP / CAUTION / SAFE at 10 Hz from Helios 32 point clouds
- 🚶 **Moving-object detection** — RANSAC ground removal, clustering, oriented 3D boxes, Kalman tracking
- 🧭 **LiDAR odometry** — vehicle motion from consecutive scans with 2D ICP, no wheel odometry needed
- 🖥️ **Control Center** — single-window Qt app to run driving, perception, recording and playback

`C++17` `Python` `ROS 2` `PCL` `Qt`
